# 角色素材

源码清单位于 `assets/characters/manifest.json`，记录每位角色的文件名、作者、作品页、画布尺寸和导出位置。当前共 162 项。

原始立绘在本地使用，公开仓库保留来源清单。准备素材时，先阅读作者当前的使用条款，从作者作品页取得图片，再保存为清单指定的 WebP 文件名，放入 `assets/characters/`。

清单中的 `width` / `height` 对应本地图片画布；`placement` 决定右下方构图。使用其他图片时，同时调整尺寸、构图与作者来源。

完整构建会检查素材是否齐全。缺图时会给出文件路径；`npm run build:code` 可在没有立绘的环境中编译，PNG 导出入口会说明需补齐素材。

涉及再分发时，应依据作者条款处理图片与打包产物。项目的 MIT License 适用于项目代码，素材使用条件由相应作者确定。
