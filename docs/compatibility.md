# 客户端兼容性

| 客户端 | 状态 |
| --- | --- |
| Windows x64 网易云 3.1.43.205627 | 已实机核对主页面、五项歌曲接口与桌面歌词菜单 |
| 其他使用 webpack 4 / Orpheus 页面的 3.x 版本 | 已加入模块编号与导出名变化的适配，等待对应版本实机验证 |
| 2.x、其他渲染架构、macOS | 当前适配范围之外 |

适配层根据歌曲接口端点定位函数，并根据原生菜单特征定位桌面歌词菜单。模块编号只作为查找提示，导出名随客户端变化时会重新解析。

当某个版本的桌面歌词菜单结构变化时，播放页及其他组件仍可加载，菜单设置可通过页面里的桌面歌词设置调整。无法识别的歌曲接口会返回具体提示，避免调用不相关的原生函数。

测试中覆盖了模块编号变化和导出名变化。实机验证与结构模拟分别记录，新增版本请提交完整版本号和实际验证结果。

官网历史安装包目前返回 HTTP 403，其他版本的实机覆盖将随可获取的安装包继续补充。
