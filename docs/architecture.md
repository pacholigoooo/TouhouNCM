# 架构

## 启动与装载

在 x64 Windows 上，启动器和常驻窗口助手共用一个 x86 可执行文件，以减少 .NET 工作集。助手通过本机调试连接与网易云通信，桌面歌词和迷你窗口按助手的指针宽度调用 Win32 窗口接口。

`Install.ps1` 将构建后的辅助程序安装到当前用户目录。`Launch.cs` 发现网易云进程并连接本机调试端口，将内嵌界面加载到主渲染进程。`ClientDiscovery.cs` 负责注册表、常见路径和用户指定路径的发现与校验。

`scripts/build.cjs` 将 renderer 模块和样式合成一份资源，交给 Windows 的 C# 编译器打包。源码目录保持功能模块拆分；安装后的辅助程序直接读取内嵌资源。

## 渲染层

- `client-api.js`：查找网易云 webpack 模块，按端点或接口特征解析原生函数。
- `bridge.js`：读取播放状态、采样时钟、歌词和队列，封装查询及控制动作。
- `view.js` / `view.css`：沉浸播放页、歌词排版和设置。
- `desktop-lyrics.js` / `caption-*.js`：歌词窗口快照、模式与菜单设置。
- `touhou-*.js` / `origin-*.js`：主题、原曲资料与曲目查询。
- `character-*.js`：角色资料、歌曲特征评分、结果界面与 PNG 排版。
- `updates.js`：GitHub Releases 查询、版本比较、更新设置和下载状态。
- `runtime-entry.js`：组件装载、订阅和统一释放。

`runtime-entry.js` 每完成一个装载动作就登记对应清理函数。重载、页面退出或中途初始化失败时，按反序释放。

## 原生窗口

`MiniSession.cs` 在主渲染进程与原生窗口之间传递状态。`NativeCdpConnection.cs` 共用一个接收循环处理请求回复、页面导航和导出唤醒事件。两个浮窗关闭后，宿主只检查原生窗口的可见性；PNG 导出通过页面 binding 唤醒。页面导航后重新注册 binding，断开时取消待处理请求。

`DesktopCaptionForm.cs` 管理歌词窗口位置、透明区域和临时断流；`DesktopCaptionPainter.cs` 缓存字体与绘制资源；`MiniPlayerForm.cs` 提供迷你窗口。

播放时钟来自原生进度采样，显示端在采样间隔内推进；切歌与跳转会重建时间基准。状态短暂缺失时保留当前歌词窗口，收到关闭信号后释放。

## 内存与资源

角色图片作为独立原生资源存储，仅在导出相应角色时传给页面。界面常驻的是素材元数据，导出结束后释放临时画布和图片引用。透明桌面歌词模式跳过背景位图分配。

播放页关闭后释放大封面与流动背景图，底栏保留 96×96 缩略图；重新打开时按当前曲目恢复。桌面歌词关闭时清空解析缓存并释放原生窗口、字体与绘制资源。播放期间仅在歌词行、主题或设置变化时发送完整内容，其余更新发送进度；逐字高亮沿用原有时钟采样频率。毛玻璃背景使用小尺寸九宫格纹理，缓存大小按 DPI 上限控制。

沉浸播放页打开时，通过 CSS 停绘被覆盖的原生黑胶、歌词和评论区，保留原生页头、页脚与进度输入。主界面的毛玻璃背景接管显示后，原生换肤背景停止绘制。规则随扩展样式一同移除，原生数据与播放控制继续运行。

主窗最小化或收至托盘且没有导出请求时，宿主等待 20 秒，再让渲染层确认页面处于隐藏状态。主窗按进程和 `OrpheusBrowserHost` 类名查找，避免 `Process.MainWindowHandle` 指向桌面歌词。桌面歌词与迷你窗口可以继续使用。CEF 91 的原生样式分配会随界面反复更新累积；渲染层在扩展样式表末尾插入并立即删除一条空规则，触发样式缓存失效，保留全部原有规则和组件。随后通过 Chromium 的 `Memory.simulatePressureNotification` 发送一次 `moderate` 通知，回收其他可再生缓存。同次后台停留执行一次，两次回收至少间隔 5 分钟。主窗恢复、导出或导航会取消闲置计时；协议不可用时停用本会话的回收功能。

## 更新

`package.json` 提供公开版本号。渲染层每 12 小时查询一次正式版，沿用原来的自动检查开关。用户手动检查和定时检查共用请求。发现新版时，启动器已有的窗口助手接收下载或取消命令。

`ReleaseUpdater.cs` 独立查询项目的 GitHub Release，从其中与版本相符的 Windows x64 资源流式下载。下载后核对长度及 Windows 版本资源里的产品名和版本，并持有文件的只读句柄直至交给安装程序。退出到系统托盘时继续听歌；网易云主进程结束后才运行当前用户的静默安装。取消、网络中断或助手解绑时会释放资源。下次启动助手时清理上次遗留的安装文件。
